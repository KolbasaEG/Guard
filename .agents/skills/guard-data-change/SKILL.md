# Изменение данных Guard

Учитывай применимые AGENTS.md/AGENTS.override.md. Определи затронутые контракт, сущности, EF-конфигурации, операции и сценарии восстановления. Целевые границы: Domain — независимые инварианты, Application — операция и доступ, Infrastructure — хранение и техническая атомарность. Существующие EF-зависимые операции в Infrastructure не являются основанием для попутного переноса или обхода доступа.

До записи согласуй единственного владельца миграций и ModelSnapshot, общих контрактов и композиции. Не редактируй применённые миграции без отдельной задачи. Не меняй подключения и секреты ради проверки.

Используй контекст на операцию с согласованным временем жизни репозиториев/транзакции. Не запускай параллельные действия на DbContext. Результат IReadRepository.QueryAsync материализуй внутри делегата. Составную запись выполняй атомарно, учитывай SaveChanges внутри CommitTransactionAsync; не сохраняй каждую строку цикла без причины. Передавай CancellationToken, отдельно обеспечивай необходимую очистку/откат.

Сохраняй PrepareAudit и доверенного автора для фабричного контекста. Проверяй все IdentityResult, конкурентные версии, ограничения уникальности, внешние ключи и удаление. Время — UTC; SpecifyKind не переводит часовой пояс.

Для поиска сохраняй порядок: серверная область → статус → выбранная иерархия → проверенный фильтр → Count → стабильная сортировка с уникальным ключом → Skip/Take → DTO Select → материализация. Не загружай граф сущностей ради таблицы. Индексы и план запроса оценивай по конкретной нагрузке, не меняя схему ради предположения.

Для дерева согласуй ParentId и Path с разделителями; запрети самого себя и потомка, не выбирай потомков по пустому префиксу. Перемещение должно атомарно менять пути ветви и учитывать конкуренцию. Проверь использование Path/varchar_pattern_ops.

Для миграции опиши совместимость выпуска, риск потери данных, подготовку и способ проверки восстановления; не обещай безусловную обратимость down. PostgreSQL-проверки выполняй на изолированной тестовой БД через существующий runner. Не запускай database update, seeding, сброс или очистку рабочей БД без отдельного разрешения. Внешние Data Skills не разрешают scaffold нового приложения, пакеты или миграции вне задачи.

Верни файлы, гарантии атомарности/конкурентности, план применения и восстановления, реальные проверки и блокеры. При неизвестном критичном правиле, выходе за область или небезопасной среде останови зависимую работу.

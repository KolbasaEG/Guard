# Проверка пробного списка IP

Ветка `codex/ip-index-dto`. Стандарт для остальных списков и AGENTS.md пока не меняется.
Обновлён только список `/ip`: таблица получает IpAddressDto, фильтр использует IpAddress.
Маппинг находится в LoadData, внутри query-делегата сервиса; полные сущности не загружаются.

После перезапуска приложения откройте `/ip` и проверьте:

1. При первом открытии данные появляются без нажатия обновления. Переключатель статусов находится по центру панели, кнопка иерархии видна. Таблица отображает подразделение, адрес и описание. Меню экспорта отсутствует.
2. При необходимости создайте больше 20 тестовых адресов, чтобы появилась вторая страница.
3. Перейдите на вторую страницу. Добавьте условие фильтра по адресу и нажмите «Применить»:
   таблица возвращается на первую страницу; счётчик соответствует отфильтрованным записям.
4. Измените условие, но не применяйте. Обновление, пагинация и сортировка продолжают
   использовать предыдущие применённые условия. После «Применить» работают новые.
5. Проверьте И/ИЛИ, вложенные группы, выбор нескольких подразделений, пустые значения.
   Очистка условий вступает в силу после нажатия «Применить».
6. Отсортируйте по подразделению, адресу и описанию в обоих направлениях.
   У одинаковых значений порядок стабилен благодаря дополнительной сортировке по Id.
7. Переключите активные/архив/удалённые. Пагинация сбрасывается; применённый фильтр сохраняется.
8. Под обычным пользователем переключите текущее подразделение/потомков: счётчик и
   записи не выходят за серверную область доступа. У Root переключатель тоже ограничивает
   список подразделением его сотрудника или этим подразделением с потомками.
   Если сотруднику не назначено подразделение, в обоих режимах список пуст.
9. Откройте «Добавить» и отмените: нет сообщения об успехе. Успешно сохраните тестовую
   запись: список обновляется, появляется уведомление установленного оформления.
10. Откройте редактор и отмените/сохраните. Проверяйте, что кнопки строки не открывают
    одновременно редактор. Заблокированные записи не открываются для редактирования.
11. Быстро меняйте страницы, сортировку и применённые фильтры. Поздний старый ответ не
    должен заменять результат последнего запроса или преждевременно снимать загрузку.
12. Под Root отзовите чтение IP у обычного пользователя, пока тот загружает список:
    старые данные не должны появиться после отзыва. Отзыв только управления скрывает
    кнопки записи и сохраняет право чтения.

Для проверки сбоя временно прервите соединение с тестовой БД разрешённым способом.
Ошибка загрузки отображается отдельным предупреждением, а не только пустой таблицей.
Восстановите соединение и нажмите обновление. Реальные настройки подключения не меняйте.

Тесты PostgreSQL проверяют снимок фильтра, И/ИЛИ, множественный выбор подразделений,
очистку, сортировку навигационного поля и DTO-проекцию. Они не заменяют ручную проверку
взаимодействия Radzen, pager и диалогов в браузере.

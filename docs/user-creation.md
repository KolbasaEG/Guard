# Создание пользователя

В разделе «Пользователи» (`/users`) кнопка «Добавить» доступна с правом
`Permissions.Users.Manage`. Root также имеет это право.

1. Нажмите «Добавить».
2. Укажите уникальное имя пользователя, email, пароль и повтор пароля.
3. Выберите сотрудника без учётной записи. Для обычного оператора доступны активные сотрудники
   собственного подразделения и его потомков, для Root — всех подразделений.
   Если список пуст, сначала создайте сотрудника в разделе «Персонал».
4. Нажмите кнопку сохранения в заголовке формы. При ошибке окно остаётся открытым
   и показывает причину: например, несовпадение паролей, слабый пароль или занятый логин.
5. После успешного создания диалог закрывается, список пользователей обновляется.
6. Под Root откройте у нового пользователя «Роли и итоговые права» и назначьте роли.
   Новая учётная запись создаётся без ролей и прикладных permissions.
7. Проверьте разрешённые IP сотрудника: пустой список запрещает вход обычному
   пользователю. Создание учётной записи не назначает IP автоматически.

Проверка в браузере: создайте тестовую учётную запись, проверьте появление в списке
и привязку к сотруднику. Попробуйте повторить тот же логин, указать разные пароли
и слабый пароль — ошибочные операции не должны создавать записи. Отмена не создаёт
учётную запись. Пользователь только с `Users.Read` не видит кнопку добавления.
При отзыве `Users.Manage` открытая форма должна блокировать отправку, сохраняя ввод.

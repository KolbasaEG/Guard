# Восстановление IntelliSense в Razor-файлах Visual Studio

## Среда и симптомы

Проблема наблюдалась в Visual Studio 2026 Community, версия 18.10.3 (Stable), в проекте Guard на .NET 10. Способ устранения проверен пользователем 7 октября 2026 года.

После открытия решения подсказки работали в первом открытом компоненте. Затем появлялось сообщение:

> Вы используете собственный компилятор TypeScript для файлов TypeScript и JavaScript.

При открытии последующих файлов `.razor` переставали работать подсказки параметров компонентов, Ctrl+Пробел, переход к определению через F12 и C#-подсказки внутри `@code`. В обычных файлах `.cs` подсказки продолжали работать. Сборка решения завершалась успешно.

## Проверенный способ устранения

1. Открыть **Средства → Параметры → Предварительные функции** (*Tools → Options → Preview Features*).
2. В поиске настроек ввести **native preview**.
3. Отключить **Enable JavaScript/TypeScript Native Language Service Preview**.
4. Сохранить изменения в параметрах и полностью закрыть Visual Studio.
5. Снова открыть решение Guard.
6. Открыть несколько разных `.razor` подряд и проверить подсказки параметров через **Ctrl+Пробел**, переход к компоненту через **F12** и C#-подсказки внутри `@code`.

После отключения этой функции и перезапуска Visual Studio пользователь подтвердил восстановление работы подсказок.

Если поиск не находит параметр, искать по словам `TypeScript` или `Native`. Название и расположение настройки могут отличаться в других версиях Visual Studio.

## Что учитывать

- Кнопка «Больше не показывать» скрывает уведомление, но не отключает языковую службу.
- Приведение файлов к CRLF в этом случае не восстановило IntelliSense. Единообразные окончания строк полезны отдельно, но не были достаточным решением этого сбоя.
- Изменение выполняется в настройках Visual Studio, а не в коде или конфигурации сборки проекта. Оно затрагивает работу языковой службы JavaScript/TypeScript в этой IDE.
- Настройка обратима: функцию можно включить снова и перезапустить Visual Studio, например после обновления IDE.
- Восстановление после отключения функции подтверждено для указанной среды. Точная внутренняя причина сбоя и его применимость ко всем установкам Visual Studio не установлены.

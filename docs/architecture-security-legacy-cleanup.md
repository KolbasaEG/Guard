# Удаление legacy-контракта управления пользователями

Дата: 17 октября 2026 года. Ветка: `codex/architecture-ip-search`. База: `0143b44`.

## Результат

Удалён ISecurityService, последний переходный сервисный интерфейс в Infrastructure. SecurityService реализует только независимые IUserAdministrationService и IUserListService из Application. В решении остаются четыре производственных и два тестовых проекта; набор 35 независимых контрактов Application не изменился. UI уже использовал узкие контракты и не менялся.

| Прежняя операция | Итог |
| --- | --- |
| GetUserByIdAsync | Удалена. Формы и тесты получают UserEditData через GetUserEditAsync |
| UpdateUserAsync(ApplicationUser, roles) | Удалена. Редактирование выполняется через SaveDetailsAsync с версией; назначения ролей остаются в IRoleAccessService |
| UpdateUserDetailsAsync | Закрытый helper SaveDetailsAsync, тело сохранено |
| ResetPasswordAsync | Закрытый helper ResetPasswordFromDtoAsync, тело сохранено |
| ToggleUserLockoutAsync | Закрытый helper SetUserLockoutAsync, тело сохранено |
| CreateUserAsync | Закрытый helper CreateFromDtoAsync. Удалён неиспользуемый производственным кодом параметр roles и ветки его обработки; создание по DTO, как и раньше, не назначает роли |

Создание пользователя и последующее назначение ролей — отдельные операции действующего интерфейса. Новая составная операция не вводилась. Транзакционная обёртка WriteAsync, контекст и UserManager на операцию, advisory lock 74162002, повторные проверки доступа, проверка обязательных IdentityResult, commit и обработка ошибок доставки аудита/уведомлений не менялись.

Удаление публичного интерфейса и CLR-методов нарушает совместимость внешних потребителей, если они существуют. Поиск подтвердил отсутствие производственных вызовов удалённых путей внутри репозитория.

## Проверки

Интеграционные проверки политики аккаунтов, редактирования, поиска/списка, доступа, версии, сброса пароля, блокировки и доставки после commit переведены на действующие DTO-контракты. Проверки возврата IdentityResult.Success заменены ожиданием завершения команды и уже существующими проверками сохранённого состояния/событий. Поэтому общий счётчик уменьшился; это не число сценариев.

Тест устаревшего создания с ошибкой назначения роли удалён вместе с самим путём. Вместо него для CreateFromDtoAsync введён одноразовый отказ в SavedChangesAsync после настоящего SQL-сохранения пользователя, до commit. Тест проверяет наличие привязки сотрудника и Identity-хеша внутри транзакции, невидимость записи из независимого подключения, распространение ошибки, отсутствие пользователя после отката и отсутствие успешного аудита. Дальнейшее успешное создание тем же сервисом проверяет освобождение контекста и транзакции.

Сохранились проверки отката обязательных IdentityResult после промежуточных SQL-сохранений для редактирования, сброса пароля, блокировки и разблокировки; они теперь вызывают публичные DTO-команды. Проверки IRoleAccessService остаются на месте. Отдельная проверка подтверждает, что редактирование профиля обычным менеджером сохраняет назначенную роль и не назначает Root.

Автоматическая граница проверяет отсутствие всех семи legacy-интерфейсов и точное совпадение публичных методов SecurityService с двумя узкими контрактами. ManagementBoundaryTests запрещает внедрение сервисных типов из Infrastructure в проверяемые компоненты. Производственные DI-регистрации и scoped lifetime обоих контрактов уже проверяются в четырёх вариантах композиции.

- Сборка: 0 ошибок, 25 прежних предупреждений Web.
- Полный Test-Guard.ps1 с PostgreSQL: **4 711 unit + 20 933 integration = 25 644**, код 0. Временная изолированная БД удалена.
- Браузерные и нагрузочные проверки не выполнялись.
- Рабочие подключения, данные, схема и миграции не менялись; приложение не запускалось.

## Дальше

Удаление прежних сервисных интерфейсов завершено. Это не завершает этапы 1–2: EF/Identity-зависимые операции ещё находятся в Infrastructure, HTTP endpoints и workers требуют сверки размещения. Следующий участок — аудит границы HTTP-экспорта и переноса транспортной обработки в Web с сохранением разрешений, атомарных переходов задания, отмены и поведения при ошибках доставки аудита. Отдельно остаются неопределённый исход commit, гарантированная доставка аудита и масштабирование проверки уникальности IP на 10 млн записей.

Предыдущий аудит: [сокращение переходного API](architecture-security-legacy-audit.md).

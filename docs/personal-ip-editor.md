# Назначение IP из формы сотрудника

1. В «Персонале» откройте редактирование существующего сотрудника.
2. Нажмите «Назначить IP-адреса» под полями сотрудника.
3. В открывшемся окне выберите один или несколько адресов/подсетей из справочника.
4. Сохраните назначения кнопкой в заголовке. После закрытия окна продолжайте
   редактировать сотрудника.

Кнопка доступна с `Permissions.IpAddresses.Manage`. Для открытия основной формы
нужны права редактирования сотрудника. Проверка подразделения и доступности IP
выполняется существующим сервисом назначения. Если адресов в справочнике нет,
сначала добавьте их в разделе «IP-адреса».

Назначения IP сохраняются отдельно. Отмена редактирования сотрудника не отменяет
уже сохранённые IP. Пустой список запрещает вход обычному пользователю. Изменения
применяются при следующем входе или новом соединении; Root освобождён от IP-проверки.

Проверка через браузер:

- Введите несохранённое изменение ФИО, откройте назначение IP и отмените его:
  основная форма и введённое значение должны остаться.
- Назначьте тестовый IP, сохраните и снова откройте назначения: выбор сохраняется.
- Отмените основную форму: изменение ФИО не сохраняется, назначенный IP остаётся.
- Снимите `IpAddresses.Manage`: кнопка исчезает, открытое окно назначения блокирует
  отправку согласно текущим правилам обновления прав.
- Проверьте, что нажатие «Назначить IP-адреса» не сохраняет основную форму.
